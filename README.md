# Python Basics Practice

Small Python scripts I wrote while learning the language, one topic per folder.

## Features

Covers data types and printing, if/else statements, loops, functions, lists, tuples, sets, dictionaries and reading files.

## Tech stack

Python 3

## Getting started

```bash
git clone https://github.com/Matiz009/python-basics-practice.git
cd python-basics-practice
python Loops/loops.py
```

## Project structure

```
Data_Types_And_Printing_It/
IF-ELSE-Statement/
Loops/
Functions/
Lists/
Tuples/
Sets/
Dictionaries/
File Reading/    fileReader.py and a sample text file
```
